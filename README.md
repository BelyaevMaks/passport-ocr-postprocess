# Постобработка OCR паспорта РФ

Решение тестового задания по интеллектуальной постобработке и фильтрации распознанных паспортов РФ в условиях асимметричной функции потерь.

---

## 🚀 Быстрый запуск

Скрипт работает на **CPU**, строго **без интернета** и **не требует установки сторонних библиотек** (только стандартная библиотека Python 3.8+):

```bash
# Запуск обработки тестового датасета
python postprocess.py data/test_predictions.jsonl answers.jsonl
```

Сверка с обучающей разметкой:
```bash
python postprocess.py data/train_predictions.jsonl train_answers.jsonl
python evaluate.py train_answers.jsonl data/train_labels.jsonl
```

## 🎯 Архитектура решения: Каскад из 8 Guardrails

Из-за жёсткого штрафа за ошибочно принятый документ ($Cost(FP) \gg Cost(FN)$) реализован консервативный каскад фильтров с математическими и нормативными гарантиями:

0. **Quality Guardrail:** Отсечение дефектных снимков по порогам бликов (`glare > 0.12`), нерезкости (`sharpness < 120.0`) и низкого разрешения (`doc_px < 1200`).
1. **MRZ Line 2 Validation (ICAO Doc 9303 TD3):** Проверка 4 независимых контрольных сумм с весами `7, 3, 1` по модулю 10 (номер, дата рождения, дата выдачи + код подразделения, композитная сумма). Из MRZ детерминированно извлекаются 5 полей из 10 со 100% математической точностью (0 ошибок на 2552 документах).
2. **Passport Validity (01.10.2026):** Проверка срока действия паспорта на 01.10.2026 в соответствии с Положением о паспорте РФ (выдача в 14 лет, замена в 20 и 45 лет + 90 дней grace period).
3. **Reference Code Matching:** Проверка существования кода подразделения в официальном справочнике `subdivisions.csv`.
4. **MRZ Line 1 Confidence:** Порог уверенности символов `min(char_conf) >= 0.995` для исключения артефактов в именах.
5. **Names Cross-check:** 1-в-1 посимвольная сверка ФИО между визуальной зоной (VIZ) и строкой MRZ Line 1 по нормативной таблице транслитерации ГОСТ/МВД (Приказ № 851) при `min_char_conf >= 0.985`.
6. **Geometry Audit:** Анализ координат рамок детектора (`box.h`, верхний, нижний и межстрочные зазоры) для предотвращения потери строк в многострочных полях `Birth_place_ru` и `Issue_organization_ru`.
7. **OCR Confidence Threshold:** Строгие пороги уверенности для текстовых полей (`Birth_place_ru >= 0.9985`, `Issue_organization_ru >= 0.985`).
8. **Reference Vocabulary Filter:** Словарная валидация всех токенов органа выдачи по официальному справочнику подразделений МВД.
